# Milestone v1.0: Dependency Cleanup

**Status:** ✅ SHIPPED 2026-04-29
**Phases:** 1-3
**Total Plans:** 6

## Overview

This milestone removed the `regedit` and VBS helper dependency from Edge discovery and packaging while preserving the existing Windows EdgeDriver login, export, and import behavior.

## Phases

### Phase 1: VBS-Free Edge Discovery

**Goal**: Users can launch login on Windows without `regedit` or VBS helpers, and the app still discovers the installed Edge path and version safely.
**Depends on**: Nothing (first phase)
**Plans**: 2 plans

Plans:

- [x] 01-01: Replace regedit-based Edge discovery with bounded PowerShell helpers in `DriverDownloader`.
- [x] 01-02: Validate the new discovery contract with compile/build evidence and a Windows login smoke check.

**Details:**
- Requirements: EDGE-01, EDGE-02, EDGE-03, SECU-01, SECU-02
- Success criteria:
  1. The app can find the installed Microsoft Edge executable on Windows without using the `regedit` package.
  2. The app can read the installed Edge product version without relying on VBS or Windows Script Host helper files.
  3. If Edge path or version detection fails, the app stops with a controlled error and logs a useful message.
  4. Registry access stays limited to the allowed Edge App Paths location, and shell execution uses fixed commands and arguments.

### Phase 2: Dependency and Packaging Cleanup

**Goal**: The runtime and build pipeline no longer depend on `regedit` or copied VBS artifacts.
**Depends on**: Phase 1
**Plans**: 2 plans

Plans:

- [x] 02-01: Remove `regedit`/`cpx2` from manifest, lockfile, build script, and active build guidance.
- [x] 02-02: Record scoped validation evidence proving no active `regedit`/VBS dependency path remains.

**Details:**
- Requirements: DEPS-01, DEPS-02, DEPS-03, VALD-03
- Success criteria:
  1. `regedit` is no longer present as a runtime dependency.
  2. `npm run build` no longer copies `node_modules/regedit/vbs/*` into `dist/vbs`.
  3. Active source and package metadata no longer contain required `regedit` or VBS references.
  4. A repository search for `regedit` and VBS only turns up intentional historical documentation, not active build/runtime dependency paths.

### Phase 3: Behavior Preservation and Validation

**Goal**: After the dependency cleanup, the app still behaves the same for login, driver management, import/export, and build validation.
**Depends on**: Phase 2
**Plans**: 2 plans

Plans:

- [x] 03-01: Record compile/build gates plus preserved driver and Electron security source-contract evidence.
- [x] 03-02: Run separate login/export/import Windows smoke checks and produce the final Phase 3 verification report.

**Details:**
- Requirements: BEHV-01, BEHV-02, BEHV-03, SECU-03, VALD-01, VALD-02
- Success criteria:
  1. The app still uses the detected Edge version to download or reuse the matching EdgeDriver.
  2. The login flow still launches Edge WebDriver from the downloaded or cached driver path.
  3. Import and export behavior remains unchanged in normal use.
  4. `npm run compile` and `npm run build` both complete successfully after the cleanup.
  5. Electron renderer security settings remain unchanged: `contextIsolation` stays enabled and `nodeIntegration` stays disabled.

## Milestone Summary

**Decimal Phases:**

- None

**Key Decisions:**

- Decision: Replace `regedit` with bounded PowerShell registry discovery to remove the VBS/Windows Script Host packaging dependency while keeping the same Edge App Paths source.
- Decision: Keep the milestone Windows-only and narrowly scoped to dependency cleanup rather than WebDriver or UI redesign.
- Decision: Treat `npm run compile`, `npm run build`, and separate Windows `login` / `export` / `import` smoke checks as the final preservation gate.

**Issues Resolved:**

- Removed the live `regedit` runtime dependency from Edge detection.
- Removed the VBS copy path from `npm run build` and eliminated the need to ship `dist/vbs`.
- Verified that cleanup did not regress login, export, or import behavior on Windows.

**Issues Deferred:**

- Non-Windows browser discovery remains out of scope.
- Automated tests for Edge discovery and WebDriver orchestration remain future work.

**Technical Debt Incurred:**

- `npm run build` still emits the known non-blocking webpack warnings around `selenium-webdriver` / `ws`.
- Milestone audit reused the approved Phase 3 smoke evidence rather than replaying a second live browser run.
